# LuxeVista Resort Mobile Application

## Project Overview

The LuxeVista Resort Mobile Application is an Android mobile application developed to improve the guest experience and simplify resort reservation activities. The application provides a user-friendly platform where guests can explore resort rooms and services, make room bookings, reserve additional services, and manage their booking information.

The system also includes an Admin interface that allows administrators to manage room and service details.

## Features

### User Features
- User registration and login
- View resort home page
- Explore available rooms
- View room details
- Book resort rooms
- View booking history
- Delete existing bookings
- Explore resort services
- Reserve additional services
- View special offers
- Manage user account details
- Receive notifications

### Admin Features
- Admin login
- Access Admin Dashboard
- Add new rooms
- View and manage rooms
- Update room details
- Delete rooms
- Search rooms
- Add new services
- View and manage services
- Update service details
- Delete services
- Search services

## Technologies Used

- **Programming Language:** Java
- **Development Environment:** Android Studio
- **User Interface:** XML Layouts
- **Database:** SQLite
- **Platform:** Android

- Use Case Diagram

## Application Architecture

The application consists of the following main components:

1. **User Interface:** Java and XML layouts are used to create the mobile application screens.
2. **Backend Operations:** Handles user authentication, room management, bookings, and service reservations.
3. **Database:** SQLite is used for local data management.

## Getting Started

### Prerequisites

- Android Studio
- Java Development Kit (JDK)
- Android Emulator (Android 8.0 / API 26 or higher) or an Android device
- USB Debugging enabled (if using a physical device)
